本目录只放交付材料与可移植源码；**请不要只在 Cursor 里写完再假装用 Qoder**。

## 推荐选题（省时间）

## 你在 Qoder 里要做的事
1. 用个人号登录 Qoder，领取 Credits
2. 新建项目，用对话完成需求拆解 → 编码 → 调试（保留截图/录屏）
3. 接入 seekdb **或** PowerContext（至少一个真实参与功能）
4. Qoder Sites 发布，可见范围 = 任何人可访问
